📝 Overview

SignFlow is a modern, secure, and easy-to-use E-Signature Platform designed to help individuals and businesses sign documents online effortlessly.
With real-time collaboration and secure encryption, SignFlow simplifies the entire e-signing process.

✨ Key Features

🖊️ Create Custom E-Signatures — Draw, upload, or auto-generate your signature.

📄 Document Upload & Signing — Upload PDFs/images and sign them digitally.

👥 Multi-Party Signing — Invite others to sign the same document.

🔒 Secure & Encrypted — Ensures your data and documents remain private.

⚡ Fast & Responsive — Built with a smooth UI optimized for all devices.

📑 Download & Share — Get your signed documents instantly.

⚙️ Installation & Setup
# Clone the repository
git clone https://github.com/Akshatcodegenics/signflow.git

# Navigate into the project folder
cd signflow

# Install dependencies
npm install

# Start the development server
npm run dev


Now visit http://localhost:3000
